Which drug trials are likely to stop early?

A termination-risk ranking for every active Phase 1–3 drug trial. Trained on trials that began 2008–2014 and tested on 2015–2016 trials whose outcomes are known. Preliminary: sponsor and FAERS features use only what was known at each start date, but registry features come from the latest version of each record, which can include edits made after the trial started. A point-in-time audit is under way.

How far to trust the score

Every number below comes from held-out 2015–2016 trials the model never saw during training. They may be optimistic until the point-in-time audit confirms them.

How the data flows

AACT registry snapshot + openFDA FAERS → Spark (flatten, match drugs, build attributes) → Parquet on GCS → Snowflake (sponsor and FAERS history as of each start date, checks, model snapshots) → LightGBM → scores back in Snowflake → this page.

What the score does not know

Registry features describe the latest version of each record, not the one at the start date, so the scores and held-out numbers may be inflated by later edits. Planned enrollment and site counts are left out because the current record already reflects the outcome. Stop reasons come from free text. FAERS features are a historical reporting signal, not a measure of drug safety: FAERS has duplicate and incomplete reports and cannot establish causation or incidence. Contributors show what moved a score, not why a trial would stop.
