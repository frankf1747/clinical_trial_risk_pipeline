# Clinical Trial Risk Pipeline — Design

## Goal

Using only what is known when a trial starts, predict which interventional drug trials will be terminated early — and test whether a drug's real-world adverse-event history (FAERS) adds signal beyond trial design and sponsor.

About 1 in 8 registered trials terminates early. Most causes (low enrollment, business decisions) are visible in the design before launch, so an early-warning ranking is realistic.

### Research questions

| # | Question | Phase |
|---|---|---|
| Q1 | How well can we rank trials by termination risk? | MVP |
| Q2 | Which design, sponsor, and therapeutic-area factors drive the risk? | MVP |
| Q3 | Does pre-start FAERS safety signal improve on a design-only model? | Scale (preliminary in MVP) |
| Q4 | Do FAERS signals predict *safety*-driven terminations specifically? | Optional |

### Scope

- **Population:** interventional drug/biologic trials, Phase 1–3, start date 2008–2020.
- **Label:** `Terminated` = 1, `Completed` = 0. Withdrawn, suspended, and still-active trials are excluded from training.
- **Scoring population:** currently active trials (not yet recruiting, recruiting, active not recruiting, enrolling by invitation).

## Data

| Source | What | Size | Access |
|---|---|---|---|
| AACT (ClinicalTrials.gov daily snapshot) | studies, designs, interventions, sponsors, conditions, eligibilities | ~2 GB pipe-delimited | Free flat-file download |
| openFDA FAERS drug/event | Adverse-event reports: report → drugs[] → reactions[] | MVP: 1 year (~5–8 GB). Full: 2004–present (100 GB+) | Bulk JSON; file list in `download.json` |

## Architecture

```
AACT, FAERS ──► GCS raw/ ──► Spark (local | Dataproc) ──► GCS parquet/ ──► Snowflake RAW → STG → INT → marts ──► Python train/score ──► TRIAL_RISK_SCORES
```

Each platform has one job:

| Component | Job | Why this tool |
|---|---|---|
| GCS | Raw landing zone + Spark's Parquet output | Dataproc and Snowflake both read it natively; data stored once. |
| Spark on Dataproc | Flatten nested FAERS JSON; match drug names | Full FAERS explodes to hundreds of millions of rows — beyond pandas. Clusters are ephemeral (create → run → delete). |
| Snowflake | Layered SQL models; point-in-time feature joins; zero-copy clone per model version; table reviewers query | Clones make each model version reproducible from the exact rows it trained on. |
| Python (scikit-learn, LightGBM, SHAP) | Train, evaluate, explain, batch-score | ~50K rows; a laptop is enough. |
| Makefile + CLI | Run stages in order or one at a time | Simplest readable entry point. |

**Not used, on purpose:** Airflow (batch, not scheduled), MLflow (versioned folder + clone is enough), Docker/Kubernetes, BigQuery, Tableau (MVP).

`MODE=local|cloud` in `.env` switches where Spark runs (laptop vs Dataproc) and where it reads/writes (`data/` vs GCS). In both modes, Parquet output is uploaded to GCS and Snowflake loads it through an external stage — one load path.

## Drug matching

Trial intervention names (plus AACT "other names") are normalized (lowercase, strip dose/route/salt words) and matched to FAERS harmonized `openfda.substance_name` / `generic_name`. Output: `trial_drug_map` (nct_id → substance) and a match-rate report. Match rate is logged, gated, and reported in the README.

## Features

Rule: **every feature is computed as of the trial's `start_date`.** Only the label comes from after.

| Group | Features |
|---|---|
| Design | phase, allocation, masking, intervention model, number of arms, primary purpose |
| Burden | number of countries, US-only flag, eligibility criteria count and text length, age range |
| Sponsor | class (industry / academic / government); sponsor's past termination rate from trials that *ended before* this one started |
| Therapeutic area | top-level MeSH condition category |
| Drug safety (FAERS) | per matched substance, reports before `start_date`: count, % serious, % death, 12-month growth |

### Leakage controls

- **Enrollment and site counts are excluded in the MVP.** AACT stores only the latest record version; finished trials report *actual* enrollment, which is low *because* the trial terminated. Scale phase S2 recovers first-registered values from record history.
- Sponsor history uses only trials completed before the current trial's start date.
- FAERS counts use only reports received before the start date.
- **Time split:** train on starts 2008–2016, test on 2017–2020. No random splits.

## Model

- Logistic regression baseline; LightGBM main model.
- Q3: design-only vs design+FAERS, same test set.
- Metrics (`metrics.json`): ROC AUC, PR AUC, precision in the top risk decile, calibration plot.
- SHAP: global top-10 drivers; top-3 drivers per scored trial.

## Versioning and scoring

Each training run writes `models/v{N}/`:

| File | Contents |
|---|---|
| `model.pkl` | Trained model (gitignored) |
| `metrics.json` | All evaluation metrics |
| `features.json` | Feature names and types |
| `manifest.json` | Git SHA, date ranges, row counts, match rate, Snowflake clone `TRIAL_FEATURES_V{N}` |

`score.py` scores active trials and appends to `TRIAL_RISK_SCORES(nct_id, model_version, risk_score, risk_decile, top_driver_1..3, scored_at)`. Append-only, so versions can be compared.

## Reliability

- **Preflight before compute:** env vars, bucket access, `LIST @stage`, Spark runtime.
- **Idempotent stages:** skip existing uploads (`FORCE=1` overrides), `CREATE OR REPLACE` tables, create Dataproc cluster only if missing and delete after the job.
- **Data gates** stop the run with a clear message:
  - fewer than 40K labeled (training) trials
  - drug match rate below threshold (set after M2)
  - termination rate outside 5–25%
  - empty test-period features

## Testing

- Unit tests run Spark locally on small fixtures (~50 trials, ~200 FAERS reports): flattening, name normalization, matching.
- Leakage tests: a FAERS report one day after start is not counted; a sponsor trial ending after start does not affect sponsor history.
- Smoke test: `make all MODE=local` on fixtures, no Snowflake.
- GitHub Actions runs unit and smoke tests.
