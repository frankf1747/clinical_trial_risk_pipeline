# Model card: trial termination risk, v6

Generated by `make report` from `models/v6/`. Trained 2026-10-04 at git `180dfe4-dirty` on the Snowflake snapshot `TRIAL_FEATURES_V6`.

## Status

**Audited on 2017–2020 starts.** Registry features come from the latest version of each ClinicalTrials.gov record, not the version at the trial's start. Scoring the same trials with registry fields as they stood at each start instead changes AUC by +0.001 (95% CI -0.001 to +0.003) on 18,568 trials (point-in-time audit below). The 2008–2016 training and test years predate the archives and could not be audited directly. AUC measures ranking. Risk percentages are calibrated on 2015–2016 starts only. Per-trial contributors describe the model, not causes of termination.

## What it predicts

- **Outcome:** a registered trial ends as `TERMINATED` (1) rather than `COMPLETED` (0).
- **Population:** interventional Phase 1–3 drug or biologic trials on ClinicalTrials.gov (AACT). Withdrawn, suspended, unknown-status and still-running trials carry no label and are excluded from training and evaluation.
- **Scored:** trials currently not yet recruiting, recruiting, active, or enrolling by invitation.
- **Intended use:** ranking active trials for review. Not intended as a probability for an individual trial's decision-making, and not a causal account of why trials stop.

## Model

LightGBM, 135 trees, 63 leaves, learning rate 0.03, min 50 trials per leaf; chosen from a 12-point grid by AUC on the inner 2013–2014 split with early stopping. The scored model is an ensemble of 10 such fits that differ only in the random seed behind row and column subsampling, with their log-odds averaged (see stability below). Baseline: logistic regression on the same tabular inputs without text.

## Limitations

- Registry features describe the latest record, not the record at start (see Status).
- Planned enrollment and site counts are excluded because the current record reflects the outcome.
- FAERS features are a historical reporting signal: FAERS has duplicate and incomplete reports and cannot establish causation or incidence. From v5 they use every quarter 2004–2026; earlier versions used the first quarter of each year.
- The test period is one two-year window of one registry; performance on other periods or registries is untested except for the rolling-origin windows above.
- Contributors are SHAP values of this model: associations, not mechanisms.
