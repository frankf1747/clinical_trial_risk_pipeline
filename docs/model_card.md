# Model card: trial termination risk, v2

Generated by `make report` from `models/v2/`. Trained 2026-09-28 at git `f00e8ad` on the Snowflake snapshot `TRIAL_FEATURES_V2`.

## Status

**Preliminary.** Registry features come from the latest version of each ClinicalTrials.gov record, not the version at the trial's start, so the held-out numbers below may be inflated by edits made after trials started. The point-in-time audit (`make audit-build audit`) has not been run for this version. AUC measures ranking. Risk percentages are calibrated on 2015–2016 starts only. Per-trial contributors describe the model, not causes of termination.

## What it predicts

- **Outcome:** a registered trial ends as `TERMINATED` (1) rather than `COMPLETED` (0).
- **Population:** interventional Phase 1–3 drug or biologic trials on ClinicalTrials.gov (AACT). Withdrawn, suspended, unknown-status and still-running trials carry no label and are excluded from training and evaluation.
- **Scored:** trials currently not yet recruiting, recruiting, active, or enrolling by invitation.
- **Intended use:** ranking active trials for review. Not intended as a probability for an individual trial's decision-making, and not a causal account of why trials stop.

## Model

LightGBM, 146 trees, 63 leaves, learning rate 0.03, min 200 trials per leaf; chosen from a 12-point grid by AUC on the inner 2013–2014 split with early stopping. Baseline: logistic regression on the same tabular inputs without text.

## Limitations

- Registry features describe the latest record, not the record at start (see Status).
- Planned enrollment and site counts are excluded because the current record reflects the outcome.
- FAERS features are a historical reporting signal: FAERS has duplicate and incomplete reports and cannot establish causation or incidence. They were built from a quarterly sample (Q1 of each year).
- The test period is one two-year window of one registry; performance on other periods or registries is untested except for the rolling-origin windows above.
- Contributors are SHAP values of this model: associations, not mechanisms.
